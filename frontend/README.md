

## Local Development (Simplified)

First, navigate to the `frontend` directory:

```bash
cd frontend
```

To install project dependencies:

```bash
npm install
# or npm i
```

To run the development server:

```bash
npm run dev
```

The application will typically be available at `http://localhost:3000`.
